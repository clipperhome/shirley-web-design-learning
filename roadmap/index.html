3-Day Web Design Learning Roadmap

Simple path to understand structure, styling, and publishing.

Day 1 — HTML Basics

Page Structure & Content Blocks

  • Learn: header, nav, section, article, footer
  • Build: one page with Hero + 3 cards + footer
  • Practice: rename headings and links
Day 2 — CSS Basics

Visual Styling & Layout

  • Learn: color, font, spacing, border, background
  • Learn: flex/grid for layout
  • Practice: make desktop + mobile look clean
Day 3 — Real Project Workflow

Update, Deploy, and Maintain

  • Replace menu images and dish photos
  • Reorder sections/items based on business needs
  • Publish to GitHub Pages and verify mobile view
