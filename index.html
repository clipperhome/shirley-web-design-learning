Common Web Design Items

Review these names while seeing live examples.

Layout

Container

Wraps content and controls max width + alignment.

Navigation

Navbar / Menu

Top links used for moving across sections/pages.

Typography

Heading + Body Text

Title hierarchy (H1/H2/H3) and paragraph readability.

UI Element

Button (CTA)

Main action users should click, like “Book Now”.

Media

Image / Gallery Item

Visual block for products, dishes, or brand photos.

Spacing

Margin / Padding

Space outside and inside boxes to improve layout.
