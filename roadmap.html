3-Day Web Design Learning Roadmap

Simple path to understand structure, styling, and publishing.

Day 1 — HTML Basics

Page Structure & Content Blocks

  • Learn: header, nav, section, article, footer
  • Build: one page with Hero + 3 cards + footer
  • Practice: rename headings and links
Day 2 — CSS Basics

Visual Styling & Layout

  • Learn: color, font, spacing, border, background
  • Learn: flex/grid for layout
  • Practice: make desktop + mobile look clean
Day 3 — Real Project Workflow

Update, Deploy, and Maintain

  • Replace menu images and dish photos
  • Reorder sections/items based on business needs
  • Publish to GitHub Pages and verify mobile view
Day 4 — Responsive Design

Mobile-First Layout Thinking

  • Learn breakpoints and flexible units
  • Practice stacking sections for small screens
  • Test navbar, cards, and images on phone size
Day 5 — Forms & UX Basics

Better User Input Experience

  • Build a full contact/reservation form
  • Add labels, placeholders, and clear button states
  • Improve readability, spacing, and accessibility
Day 6 — Visual Polish

Brand Consistency & Components

  • Create a color + typography style guide
  • Standardize buttons, cards, and section spacing
  • Add subtle hover effects and micro-interactions
Day 7 — Final Project

Restaurant Website Build

  • Build a full 1-page restaurant site from scratch
  • Add menu section, gallery, about, and contact
  • Publish via GitHub Pages and do final QA checklist
Day 8 — JavaScript Basics

Make Pages Interactive

  • Learn variables, functions, and events
  • Add a button click interaction
  • Update text/content dynamically with JS
Day 9 — DOM Practice

Work with Elements on the Page

  • Select elements and change styles/content
  • Build a simple show/hide section
  • Create a basic image switcher
Day 10 — Navigation & Components

Reusable UI Blocks

  • Build reusable card/button patterns
  • Create a sticky mobile-friendly navbar
  • Add active state to menu links
Day 11 — Accessibility Basics

Design for Everyone

  • Use semantic HTML and proper labels
  • Improve color contrast and text size
  • Test keyboard navigation flow
Day 12 — Performance & Images

Faster, Cleaner Website Loading

  • Compress and optimize images
  • Use modern formats where possible
  • Audit page size and loading behavior
Day 13 — Mini Project

Build a Full Menu + Gallery Page

  • Create a polished restaurant landing page
  • Include menu, dish grid, and contact section
  • Review spacing, typography, and mobile fit
Day 14 — Publish & Review

Final QA + Deployment

  • Run final mobile and desktop checks
  • Fix broken links and alignment issues
  • Publish final version on GitHub Pages
